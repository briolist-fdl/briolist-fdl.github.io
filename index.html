Brio Bots Backups

Brio Bots Backups helps the operator protect the databases behind these tools. It encrypts database exports before uploading them to the operator’s Google Drive and checks the uploaded files.

Google sign-in connects the operator’s account to the backup tool. Discord members do not need to connect a Google account. This tool is not offered as a public backup service.

Limited Google Drive access

The application requests access to files it creates or files explicitly made available to it through Google’s per-file permission. It does not request general access to all files in Google Drive.

The application is being prepared for use. Automated scheduling and retention are not yet active.
