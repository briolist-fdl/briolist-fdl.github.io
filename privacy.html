BRIO BOTS BACKUPS

Privacy notice

Updated 25 September 2026

This notice covers the BrioBots Backups operator tool and this website. It does not replace the separate privacy information for each Discord bot. The tool is maintained by briolist-fdl.

Google account access

The operator authorizes access using Google OAuth. The requested drive.file permission allows the application to access files it creates and files explicitly made available to it. It does not grant access to all documents in the account. The tool uses this access to upload encrypted archives and read file metadata, including names, identifiers, sizes and checksums, to verify those uploads.

Information stored

The connection stores OAuth credentials, including a refresh token, in the operator’s local configuration or the backup runner’s secret settings. These credentials are not published in the website or source repository. Backup filenames and operational records may include a database label, timestamp, file size and checksum.

Encrypted database archives may contain Discord user identifiers, friend code profile data and bot settings, depending on the database selected by the operator. Database contents are encrypted before upload. The private decryption key is kept separately from the backup runner.

Purpose and sharing

Google user data is used only to operate and verify backups and support recovery. It is not sold, used for advertising or used to train AI models. Encrypted archives and their metadata are stored by Google Drive. The operator and any infrastructure running the configured backup job process the information needed to carry out that job. Files are not intentionally shared publicly by the backup tool.

Retention and deletion

Retention depends on the configured backup job. Archives may remain until the operator removes them or the documented retention policy removes them. A backup can contain data deleted from the live database after that backup was made. Recovery must account for those later deletions before a restored bot is put into use.

The operator can revoke the application’s connection through Google Account connections. Revocation stops future authorized access but does not delete existing archives. Existing files can be removed separately in Google Drive.

This website

This static website has no sign-in form, analytics scripts or advertising. GitHub Pages hosts it and may log visitor IP addresses for security purposes, as described in the GitHub Privacy Statement.

Contact and changes

Questions can be directed to briolist-fdl on GitHub. Do not post credentials or private personal information in a public issue. This notice will be updated when the tool’s data practices change.
